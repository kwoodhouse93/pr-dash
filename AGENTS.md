# Agent notes

When you change files in this repository, commit the change and push it to `main` before you finish. Do not wait to be asked.

- Commit on `main` and push to `origin/main`.
- Stage only the files for the change. Leave unrelated edits alone.
- Do not commit secrets (`.env`, credentials, tokens).
- Do not force-push `main`, skip hooks, or change git config.
- Skip the commit when there is nothing to commit, or when the user said not to commit or push.
